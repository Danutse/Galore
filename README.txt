
Galore Launcher is a Windows desktop control center for starting programs

tracking running applications organizing access items managing small

desktop tools and keeping a personalized launcher layout.


WHAT GALORE DOES

- Launches or ends the programs you set up.

- Lets you pick programs start or end the selected group,

or do something with every program that is set up at the same time.

- Lets you change any programs executable from its right-click menu.

- Provides four program categories, each with up to five programs.

- Shows a built-in file and application search window.

- Displays CPU, RAM, GPU and GPU temperature information.

- Provides access icons for files, folders, shortcuts and web shortcuts.

- Mirrors normal Windows application windows in the left-side taskbar.

- Includes network retry, volume, keyboard-language, calculator and post-it

tools.

- Saves your window placement, program choices, categories, post-its and

quick-access layout automatically.


INSTALLATION

1. Run GaloreLauncherSetup.exe.

2. Choose the folder where you want Galore installed.

3. Open GaloreLauncher.exe from that installation folder.

The installed release creates its Settings, Logs and program-data folders as

needed. No PowerShell module folder is required beside the installed EXE.


FIRST-TIME SETUP

1. Right-click a program name to choose the executable it should manage.

2. Left-click its name or checkbox to include or exclude it from selected

actions.

3. Use Launch All, Terminate All Launch Selected or Terminate Selected.

4. Right-click a category button to configure, up to five programs.

5. Drag a supported file, folder,.lnk shortcut or.url shortcut onto the

quick-access bar.
